# 0.1.0a1 — alpha release notes

**Status: prepared locally; not published.** Hermes Voice Assistant by Devsdroid.com is an independent community voice dashboard for Hermes Agent, not an official Nous Research product. Original dashboard code uses the [MIT License](../../LICENSE); dependencies and voice models retain their separate licenses. Publication has not been authorized.

## Included

- Studio workspace with Core/Daylight themes, measured microphone/playback visualization, reduced-motion behavior and immediate Classic fallback.
- Multiple conversations with local SQLite history, title search, archive and JSON export.
- Separate chat and explicitly dispatched tool-enabled workers, server-owned tasks across browser reconnects, cancellation and session-bound approvals.
- Optional guided setup with explicit runtime/model/microphone/speaker checks; no automatic Hermes installer or browser credential entry.
- Local Whisper transcription and optional Edge, ElevenLabs, OpenAI or local Piper speech, with voice search and previews. Text-only remains the default.
- Bounded completed-reply speech chunks, one-chunk prefetch and interruption handling.
- A reversible, **default-off early-speech trial** for tool-free chat. No useful early-audio benefit was demonstrated on the tested runtime: all three live trial runs started audio after model completion. Timing differences are not proof of streaming acceleration. See [trial evidence and limits](../early-speech.md).

See the [README screenshots](../../README.md#screenshots), [installation guide](../installation.md) and [voice provider setup](../voice-providers.md).

## Recorded verification

Local regression results: **100 Python tests, 55 browser tests and 18 Node speech/geometry tests passed**. Real prerecorded microphone → Whisper → configured model → Edge playback was exercised. Live Piper/Edge playback and session/worker workflows were also checked; paid OpenAI/ElevenLabs contract tests are not live-provider certification.

Hermes inference was exercised on macOS with Python 3.11 and Hermes revision `21b2095d00`. Clean macOS Python 3.12 wheel checks covered UI/storage and missing-runtime onboarding, not a full independent Hermes installation. Builds and local lint/syntax checks were recorded as passing. The release-preparation run repeated deterministic checks and exercised 55 browser tests against the clean installed wheel with Hermes absent. These are local results, not remote release CI.

## Known limitations and release gates

- Remote CI and Windows/Linux execution have not been verified.
- No full-duplex barge-in, wake word, native realtime audio or automatic chat-to-worker routing.
- Keep the service on loopback: no authenticated multi-user hosting or filesystem sandbox. Cancellation cannot reverse completed side effects.
- Server restart interrupts uncertain tasks rather than replaying them; durable approval recovery, task steering and artifact downloads are not implemented.
- Large-history pagination, load testing, retention UX and formal accessibility/security audits remain work.
- Cloud model/TTS requests may transmit text and incur charges; local-first is not a promise of offline operation.
- Dependency/model attribution review, private security reporting, publication destination and owner authorization remain unresolved. No PyPI release, GitHub release, live download URL or platform-support badge is claimed here.
