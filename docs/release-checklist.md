# Public release checklist

Preparation is local. Nothing here authorizes creating a remote, uploading source or publishing a release.

## Verified preparation

- [x] Original dashboard code licensed MIT by owner choice; LICENSE and package metadata added.
- [x] Direct-dependency license inventory and optional Piper/Edge/model caveats documented; no bundled runtime/model weights.
- [x] Screenshot-led README, alpha notes, contribution/security guidance and draft About/topics prepared.
- [x] Studio Core/Daylight screenshots refreshed from isolated empty data and documentation images reviewed for visible private information.
- [x] 100 Python, 55 browser and 18 Node speech/geometry checks passed locally.
- [x] Clean macOS Python 3.12 wheel onboarding/save/restart checked with Hermes absent; not a full independent Hermes setup.
- [x] Cross-origin framing gap reproduced, fixed and checked in a real browser; top-level use remains available.
- [x] Explicit public-source candidate builder rejects symlinks, checks relative documentation links, scans selected secret/path patterns and verifies ZIP read-back hashes.

See [verification scope](release-verification.md), [third-party notices](../THIRD_PARTY_NOTICES.md) and [draft metadata](github-metadata.md).

## Still required before public launch

- [ ] Confirm destination owner/organization and repository slug; obtain explicit publication authorization.
- [ ] Establish and verify a private vulnerability-reporting channel.
- [ ] Review exact release artifacts and audit all staged content plus the complete intended Git history after repository creation/import.
- [ ] Review transitive dependency and model licenses/obligations for the intended distribution; MIT does not relicense optional LGPL/GPL components.
- [ ] Verify a fresh independent Hermes-enabled installation and any platform/version to be advertised.
- [ ] Execute remote CI; configuration alone is not a passing run.
- [ ] Read back published repository metadata, source, release assets and security-reporting configuration after authorized upload.

## Not claimed by this alpha

Production security certification, real-room voice quality, comprehensive accessibility/load testing, Windows/Linux support and useful model/audio streaming overlap are not established. The streaming trial remains default-off. No unsupported badges, fabricated metrics or search-ranking guarantees.
